# Google 拼音输入法 T+ 2.1.0

本版本将 T+ 双字母布局和拼音笔画过滤移植到上游 `v2.0.10` 的 Android 16 正式基线。T+ 的点按、左右短滑、长按、自动笔画轨迹和候选过滤保持，同时获得现代设置、统一 Header、Inline Autofill、简繁快捷切换及近期稳定性修复。

## 主要更新

- 基线升级：target SDK 从 28 提升到 36，继承 Android 15/16 covering-IME、导航区域、edge-to-edge 与动态高刷新率适配。
- 现代设置：Android 15 及以上使用 Compose Material 3，Android 14 及以下保持旧 Preference 设置。
- 统一 Header：T+ 候选区域接入 Candidate、敏感 Clipboard 与 Android 11+ Inline Autofill 仲裁。
- 简繁切换：T+ 与中文 QWERTY、九键和笔画布局都支持原生「简/繁」快捷按钮及显示开关。
- T+ 长按修复：L、M 和双字母键的数字、标点、小写及大写候选保持独立，不再整串提交候选标签。
- 稳定性：合入电话键盘类链接、拼音组合文本高度、未测量键盘切换、密码输入框高度和符号分页区域外松手修复。
- 发布身份：Application ID 继续使用 `com.google.android.inputmethod.pinyin.compat.tplus`，可覆盖升级 T+ 1.1.0，并可与上游正式版并存。

## T+ 输入说明

- 关闭「拼音笔画过滤」时，可使用 Google 拼音跨键滑行输入。
- 开启「拼音笔画过滤」后，候选出现即可直接在 T+ 键盘主体书写笔画。普通点按与静止长按保持原行为。
- 自动笔画轨迹使用当前键盘主题颜色，松手后淡出。数据或会话异常时恢复原拼音候选顺序。

## 兼容边界

- APK 仅提供 `arm64-v8a`。
- TalkBack touch exploration 下的 Inline Suggestions 使用系统回退路径。
- Android 17/API 37、Predictive Back 和强制 16 KiB native page-size 运行时验收仍属于后续工作。

## 升级

从 T+ 1.1.0 覆盖安装时必须使用本项目相同正式签名。Android `versionCode` 已从 `4520406` 递增到 `4520407`，不会修改已发布的 `tplus-v1.1.0` Release 或资产。

## 发布验收

- 最终 APK 从固定原始包完成全量 Compose Host 重建，保留 6,633 个旧公开资源 ID。包名、版本、target SDK 36、`arm64-v8a`、v1/v2/v3 签名与 16 KiB ZIP alignment 均通过。
- 两次独立干净解码应用补丁后，5,742 个输出文件逐项一致。
- 在 4 KB/API 34 和 4 KB/API 36 模拟器从 T+ 1.1.0 覆盖安装，原 `firstInstallTime`、T+ 布局选择和笔画过滤设置保持。
- API 34 旧 Preference 与 API 36 Compose Material 3 均可显示和持久化「拼音笔画过滤」。
- L 长按显示独立的 `L`、`l`、`0` 候选，松手只提交一个字符。开启笔画过滤后行为不变。
- T+ 普通点按可生成原生拼音候选。开启笔画过滤后跨键横划显示主题色轨迹，并将候选过滤为横起笔结果。API 36 符号页横向分页正常。
- 两台模拟器的相关日志未发现崩溃、ANR、VerifyError 或类加载错误，测试后均恢复原默认输入法。
